--------------------------------------------------------------------
TROUBLESHOOTING QUICK MAP
--------------------------------------------------------------------

1) "Port already in use"
- Kill process on 8000 and restart.

2) Health works but prune hangs/timeouts
- Check /tmp/swe_pruner.log for traceback.
- Retry with tiny code payload first.

3) "model type qwen3 not recognized"
- Your transformers version is incompatible with the current local setup.
- Reinstall the project in the workspace venv and use the known working setup used in this workspace.

4) Torch missing
- Install torch in the same venv used to start server.

5) LFS download failed
- Use Hugging Face download command instead of git lfs pull.

6) 422 Unprocessable Entity / "JSON decode error"
- You have a trailing comma in the JSON payload (e.g., "threshold": 0.45,})
- Fix by removing the trailing comma before the closing brace
- Swagger UI may auto-generate trailing commas; always validate before copying curl commands
