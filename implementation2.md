# Implementation Plan: Evidence-Aware Workspace Goal Generation and AST-Based Repository Pruning

This plan establishes the architecture and implementation design for extending the **TokenWise** framework from single-file local skimming to a repository-level context compression pipeline. It combines **evidence-aware local goal compilation** (using a lightweight instruction model) and **multi-file AST dependency-graph traversal** with Qwen3-Reranker-based pruning.

---

## 1. Connected Pipeline Flow

The system coordinates the following pipeline steps for repository pruning:

```
[VS Code Client]
   │ (Collects: User query, selected code, active symbol, diagnostics, stack trace)
   ▼
[FastAPI /prune-workspace]
   │
   ├──► [Goal Compiler & Generator] ──► Query local Qwen2.5-Coder-1.5B-Instruct
   │                                    (Synthesizes Structured Goal JSON)
   │
   ├──► [AST Python Indexer] ─────────► Extract functions, imports, callers, callees, tests
   │                                    (Builds Repository & Dependency Graph)
   │
   ├──► [Graph & Lexical Retriever] ──► Find 1-hop dependencies, references, tests
   │
   ├──► [SWE-Pruner Candidate Ranker] ► Rerank retrieved candidate symbols via document score
   │
   └──► [Context Builder] ────────────► Prune lines and pack symbols into 3-tier presentation
                                        (Global token budget packing)
```

#### [NEW] [goal_generator_client.py](file:///e:/A%20A%20SPL3/part-2/swe-pruner/swe-pruner/swe-pruner/src/swe_pruner/goal_generator_client.py)
Manages connection interfaces to the local `Qwen2.5-Coder-1.5B-Instruct-Q4_K_M` running via llama.cpp or Ollama:

```python
import json
import httpx
from typing import Optional
from .goal_models import StructuredGoal

class LocalGoalGeneratorClient:
    def __init__(self, endpoint_url: str = "http://127.0.0.1:11434/v1"):
        self.endpoint_url = endpoint_url

    async def generate_goal(self, prompt: str) -> Optional[StructuredGoal]:
        try:
            async with httpx.AsyncClient(timeout=10.0) as client:
                response = await client.post(
                    f"{self.endpoint_url}/chat/completions",
                    json={
                        "model": "qwen2.5-coder:1.5b-instruct-q4_k_m",
                        "messages": [{"role": "user", "content": prompt}],
                        "response_format": {"type": "json_object"},
                        "temperature": 0.0,
                    }
                )
                if response.status_code == 200:
                    data = response.json()
                    content = data["choices"][0]["message"]["content"]
                    parsed = json.loads(content)
                    return StructuredGoal(**parsed)
        except Exception:
            return None
```

#### [NEW] [goal_compiler.py](file:///e:/A%20A%20SPL3/part-2/swe-pruner/swe-pruner/swe-pruner/src/swe_pruner/goal_compiler.py)
Assembles editor metadata, triggers the generator client, enforces fallback patterns, and filters hallucinated symbol identifiers:

```python
from typing import List
from .goal_models import StructuredGoal

class GoalCompiler:
    def __init__(self, generator_client: LocalGoalGeneratorClient):
        self.generator = generator_client

    def build_prompt(self, query: str, active_file: str, current_symbol: Optional[str], 
                     selected_code: Optional[str], diagnostics: List[str]) -> str:
        return f"""
        You are a goal synthesizer. Rewrite the user's vague query into a precise goal description.
        Use the following editor context:
        - Query: "{query}"
        - File: {active_file}
        - Current Symbol: {current_symbol or 'None'}
        - Selected Code: {selected_code or 'None'}
        - Diagnostics: {diagnostics}
        
        Respond ONLY with a JSON object fitting the StructuredGoal schema.
        Do not invent class or function names not present in the provided context.
        """

    async def compile(self, query: str, active_file: str, current_symbol: Optional[str], 
                      selected_code: Optional[str], diagnostics: List[str]) -> StructuredGoal:
        prompt = self.build_prompt(query, active_file, current_symbol, selected_code, diagnostics)
        goal = await self.generator.generate_goal(prompt)
        
        # Fallback if local LLM fails or is unavailable
        if not goal:
            goal = self.deterministic_fallback(query, current_symbol, diagnostics)
            
        # Post-process: Remove invented identifiers
        valid_words = set(query.split() + ([current_symbol] if current_symbol else []))
        if selected_code:
            valid_words.update(selected_code.split())
        goal.identifiers = [ident for ident in goal.identifiers if ident in valid_words]
        
        return goal

    def deterministic_fallback(self, query: str, current_symbol: Optional[str], diagnostics: List[str]) -> StructuredGoal:
        return StructuredGoal(
            task_type="generic_task",
            objective=f"Process intent '{query}' related to symbol '{current_symbol or 'unknown'}'",
            identifiers=[current_symbol] if current_symbol else [],
            observed_errors=diagnostics,
            required_context=[],
            retrieval_questions=[],
            clarification_required=True if not query and not current_symbol else False
        )
```

### 2.2 Backend Core: AST-Based Python Repository Indexer

#### [NEW] [python_indexer.py](file:///e:/A%20A%20SPL3/part-2/swe-pruner/swe-pruner/swe-pruner/src/swe_pruner/repository/python_indexer.py)
Parses Python source files using the standard `ast` module to build structural class, function, method, and import registries:

```python
import ast
from pathlib import Path
from typing import Dict, List, Any

class PythonASTIndexer:
    def index_file(self, file_path: Path) -> Dict[str, Any]:
        try:
            content = file_path.read_text(encoding='utf-8')
            tree = ast.parse(content, filename=str(file_path))
        except Exception:
            return {"classes": {}, "functions": {}, "imports": []}

        classes = {}
        functions = {}
        imports = []

        for node in ast.walk(tree):
            if isinstance(node, ast.ClassDef):
                classes[node.name] = {
                    "start_line": node.lineno,
                    "end_line": getattr(node, "end_lineno", node.lineno),
                    "methods": [n.name for n in node.body if isinstance(n, ast.FunctionDef)]
                }
            elif isinstance(node, ast.FunctionDef):
                functions[node.name] = {
                    "start_line": node.lineno,
                    "end_line": getattr(node, "end_lineno", node.lineno)
                }
            elif isinstance(node, ast.Import):
                for name in node.names:
                    imports.append(name.name)
            elif isinstance(node, ast.ImportFrom):
                imports.append(node.module or "")
                
        return {"classes": classes, "functions": functions, "imports": imports}
```

#### [NEW] [repository_index.py](file:///e:/A%20A%20SPL3/part-2/swe-pruner/swe-pruner/swe-pruner/src/swe_pruner/repository/repository_index.py)
Walks the workspace directory tree and maintains the active in-memory repository structure index:

```python
import os
from pathlib import Path
from typing import Dict, Any
from .python_indexer import PythonASTIndexer

class RepositoryIndex:
    def __init__(self, workspace_root: str):
        self.workspace_root = Path(workspace_root)
        self.indexer = PythonASTIndexer()
        self.index: Dict[str, Any] = {}

    def build_index(self):
        for root, _, files in os.walk(self.workspace_root):
            for file in files:
                if file.endswith('.py'):
                    full_path = Path(root) / file
                    rel_path = str(full_path.relative_to(self.workspace_root))
                    self.index[rel_path] = self.indexer.index_file(full_path)
```

#### [NEW] [dependency_graph.py](file:///e:/A%20A%20SPL3/part-2/swe-pruner/swe-pruner/swe-pruner/src/swe_pruner/repository/dependency_graph.py)
Establishes logical relationship edges between classes, methods, imports, and tests (e.g., caller-callee mappings):

```python
from typing import Dict, Set, List
from .repository_index import RepositoryIndex

class DependencyGraph:
    def __init__(self, repo_index: RepositoryIndex):
        self.repo_index = repo_index
        self.adjacency_list: Dict[str, Set[str]] = {}

    def build_graph(self):
        # Scan imports and symbol names to establish link edges
        for rel_path, meta in self.repo_index.index.items():
            self.adjacency_list[rel_path] = set()
            for imp in meta.get("imports", []):
                # Simple import matching to identify relative repository dependencies
                for target_path in self.repo_index.index:
                    target_mod = target_path.replace('.py', '').replace('/', '.').replace('\\', '.')
                    if imp in target_mod or target_mod.endswith(imp):
                        self.adjacency_list[rel_path].add(target_path)
```

#### [NEW] [lexical_retriever.py](file:///e:/A%20A%20SPL3/part-2/swe-pruner/swe-pruner/swe-pruner/src/swe_pruner/retrieval/lexical_retriever.py)
Executes rapid matching searches across the codebase using tokens extracted from the synthesized Goal JSON:

```python
from typing import List, Set
from ..repository.repository_index import RepositoryIndex

class LexicalRetriever:
    def __init__(self, index: RepositoryIndex):
        self.index = index

    def search_identifiers(self, identifiers: List[str]) -> Set[str]:
        matched_files = set()
        for rel_path, file_meta in self.index.index.items():
            for ident in identifiers:
                # Check for class or function signature definitions
                if ident in file_meta.get("classes", {}) or ident in file_meta.get("functions", {}):
                    matched_files.add(rel_path)
        return matched_files
```

#### [NEW] [graph_retriever.py](file:///e:/A%20A%20SPL3/part-2/swe-pruner/swe-pruner/swe-pruner/src/swe_pruner/retrieval/graph_retriever.py)
Traverses the dependency network to find relevant direct graph neighbors (transitive callers, callees, and corresponding tests):

```python
from typing import Set
from ..repository.dependency_graph import DependencyGraph

class GraphRetriever:
    def __init__(self, graph: DependencyGraph):
        self.graph = graph

    def get_neighbors(self, seed_files: Set[str], max_hops: int = 1) -> Set[str]:
        neighbors = set(seed_files)
        current_layer = set(seed_files)
        
        for _ in range(max_hops):
            next_layer = set()
            for file in current_layer:
                if file in self.graph.adjacency_list:
                    next_layer.update(self.graph.adjacency_list[file])
            next_layer = next_layer - neighbors
            neighbors.update(next_layer)
            current_layer = next_layer
            
        return neighbors
```

#### [NEW] [candidate_ranker.py](file:///e:/A%20A%20SPL3/part-2/swe-pruner/swe-pruner/swe-pruner/src/swe_pruner/retrieval/candidate_ranker.py)
Uses the global document score prediction (`score_logits`) from the existing pre-loaded `Qwen3-Reranker-0.6B` model to rerank the candidates:

```python
import torch
from typing import List, Tuple
from ..swepruner import SwePrunerForCodeCompression

class CandidateRanker:
    def __init__(self, pruner_model: SwePrunerForCodeCompression):
        self.model = pruner_model

    def rank_candidates(self, query: str, candidates: List[Tuple[str, str]]) -> List[Tuple[str, float]]:
        # candidates is a list of (file_path, file_content)
        ranked = []
        for path, content in candidates:
            # Tokenize & call backbone forward to fetch document score logits
            inputs = self.model.tokenizer(
                f"<Instruct>: Retrieve relevant code\n<Query>: {query}\n<Document>: {content}",
                return_tensors="pt"
            )
            with torch.no_grad():
                outputs = self.model(
                    input_ids=inputs["input_ids"].to(self.model.device),
                    attention_mask=inputs["attention_mask"].to(self.model.device)
                )
                score = float(outputs.score_logits[0].cpu().numpy())
                ranked.append((path, score))
        return sorted(ranked, key=lambda x: x[1], reverse=True)
```

#### [NEW] [context_builder.py](file:///e:/A%20A%20SPL3/part-2/swe-pruner/swe-pruner/swe-pruner/src/swe_pruner/retrieval/context_builder.py)
Assembles the final pruned multi-file context response. It classifies retrieved targets into three priority tiers to avoid token budget overflow:

*   **Tier 1: Critical Target Symbol**: Kept completely or lightly pruned using a high threshold.
*   **Tier 2: Direct Dependencies (1-hop)**: Includes class definitions and signature headings with heavily pruned bodies.
*   **Tier 3: Transitive Dependencies (2-hop / related symbols)**: Includes class declarations and method signatures only (all logic bodies stripped).

```python
from typing import List, Dict, Any

class ContextBuilder:
    def __init__(self, token_budget: int = 8192):
        self.token_budget = token_budget

    def pack_context(self, tier1_symbols: List[Dict[str, Any]], 
                     tier2_symbols: List[Dict[str, Any]], 
                     tier3_symbols: List[Dict[str, Any]]) -> str:
        output_blocks = []
        
        # 1. Pack Tier 1 (Full/lightly pruned body)
        for sym in tier1_symbols:
            output_blocks.append(f"### {sym['path']} (Target)\n{sym['code']}")
            
        # 2. Pack Tier 2 (Signature + pruned body)
        for sym in tier2_symbols:
            output_blocks.append(f"### {sym['path']} (Dependency)\n{sym['signature']}\n{sym['pruned_body']}")
            
        # 3. Pack Tier 3 (Signatures only)
        for sym in tier3_symbols:
            output_blocks.append(f"### {sym['path']} (Interface Reference)\n{sym['signature']}")
            
        return "\n\n".join(output_blocks)
```

## 3. User Review Required

> [!IMPORTANT]
> **Performance Overhead**: Running `Qwen2.5-Coder-1.5B-Instruct` locally adds a minor inference latency penalty (~1-2 seconds) to build the initial Structured Goal. We address this by running the local client in streaming-JSON mode or falling back to deterministic templates immediately if query latency exceeds 3.0 seconds.

> [!WARNING]
> **AST Language Constraints**: The initial AST indexer targets Python (`.py`) syntax structure natively using the standard library `ast` module. Other languages will fall back to lexical pattern-matching import resolution until individual AST parser modules are written.
